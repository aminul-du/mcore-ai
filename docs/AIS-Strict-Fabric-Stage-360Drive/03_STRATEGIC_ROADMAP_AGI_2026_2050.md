## Immediate MCORE Startup Setup Advice & Strict Boundaries Workflows

1. **Capital Allocation & Zero-Cost Architecture:** Maintain Cloudflare free tier + sovereign owned bare-metal compute. Avoid commercial SaaS token billing for continuous audio/media ingestion.
2. **Prevent Task Duplication:** All tasks must be logged in `task-ledger.yaml`. Do not replicate running agents across overlapping ports (Port 3000 = Frontend, Port 7860 = Voice Console, Port 7880 = LiveKit, Port 8000 = API/Library, Port 8100 = Memory Trust Engine).
3. **Telemetry & Audit Rigor:** Every deployment must generate an automated SHA verification report. Untracked manual changes are strictly prohibited in production branches.
